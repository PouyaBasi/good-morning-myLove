# Parisa's sunrise website

Files (no install, no build, nothing to download):
- index.html  -> the whole website
- Ticket.pdf  -> the surprise file she downloads (keep it next to index.html)

Test tips (add to the end of the page address):
- ?step=3  jumps to step 3 (0 to 6)
- ?reset   clears answers saved in the browser

Optional: get her answers by email
1. Go to formspree.io, make a free account, create a form, copy its URL.
2. Open index.html, find FORM_ENDPOINT near the top of the script, paste the URL between the quotes.
3. Upload index.html again. (Her "happy" answer is never sent or saved.)
